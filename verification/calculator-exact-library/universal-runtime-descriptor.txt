MA1 universal source-to-runtime ABI contract, 2026-10-08

Scope: selected Signed-Declared-Text-v1 session; unchanged original per-definition 4096, module 16384, source work 2,000,000, Wasm 4096, runtime allocation 65536. Not Worker, live, or raw Submission ingress. This is the agreed implementation contract, not an executable waiver, test result, or evidence of successful compiler admission.

Kernel source: private source owner matches its exact original retained whole module bytes, definition spans, owner and import aliases; rechecks current grant/effect state. Only source-authenticated pure forall<S:stack> with the same rigid opaque S, including recursively quoted same-owner invocation, may carry CheckedScheme. Each finite use is independently instantiated with the original owner and dependency stamps to CheckedInstantiation: every lexical node has its concrete input/output, full type/effect ABI, Definition and Inst. The kernel seal is not a source credential. Stable owner Definition rows never retarget as later modules append; unrelated monotonic Env extension is permitted, relevant row mutation or stale dependency rejected. No concrete sampling or host-computed result.

Compiler source ingress: private source-verified closure exclusively; no public caller-supplied numeric code entry/CodeSpan, raw seal, or fabricated Submission. Closure binds the lexical source tree, checked symbolic body, every concrete use/quote/self node, owner Definition and original source identity, same-generation body+quote code entries, exact CodeSpan/table owner and pinned dependency DAG. Compiler and host independently compare every old code-entry identity to the previously accepted installed owner; fail closed if unavailable. Compile each universal owner body and each lexical quotation once per original owner/generation, never once per use; original compiler ABI guards remain until complete bridge and negative checks exist.

Runtime ABI: shared source-epoch linear memory/table and immutable pinned old code spans. An old generic $fN($env) resolves invocation/quotation/self targets through the instance-specific immutable descriptor referenced by the executing Program cell's `a` field, never a stale old-module `$sN` global. Descriptor records bind lexical node, exact checked concrete y/z/effects, target slot and checked owner/source identity. New instance builds one correctly typed Program cell for each concrete body/quote using the existing accepted old code entry, child recipe and exact ABI; a uniquely allocated table slot is filled exactly once with that cell handle before publication. A quoted self-reference is represented by a slot indirection, not a cyclic child cell/recipe; all immutable Program child identities remain acyclic and valid under linear child<parent rules. At runtime each read checks descriptor bounds, target cell kind Program, full y/z/effect identity and epoch; no mutable retarget or incomplete slot is callable. Source, compiler and host charge descriptor, cell, and traversal costs under their existing original bounds.

Publication/lifecycle: exact owner/source/Env/CodeSpan/table-root/epoch preflight precedes any visible install. Stage owner code and concrete instance slots/cells under an isolated pending transaction, initialize slots once, check full DAG and ABI, then atomically publish; failure rolls back unpublished cells/table/roots or poisons without exposing a partial instance. The engine retains/pins accepted old sourceModules and code spans until all source external handles, stack, continuations and observations are clear; old-generation Program handles retain original owner identity and cannot silently rebind to a new same-name owner. Source epoch retirement clears all source module roots, descriptor references, non-core table entries and heap together; original Core bridge table entries 0..3 stay unchanged. Root-grant Worker scope, live CodeSpan retirement and combined34f remain unchanged. No direct invocation compile, host arithmetic fallback, new VM primitive, or bypass of the original signed-source guards without a static security reviewer GO and an exclusive test slot.

If shared epoch text descriptor memory or write-once slot integrity cannot be proven with the existing VM primitives, the feature fails closed at admission and names the exact unsupported primitive; it does not simulate indirection by mutable unverified globals or abandon the full ABI checks.
