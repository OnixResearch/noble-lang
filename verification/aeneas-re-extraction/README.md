## Re-running

Regenerate and check the subjects with the selected Node from a clean checkout:

```sh
SELECTED_NODE verification/m4/implementation.mjs discover NEW_DIRECTORY_OUTSIDE_THE_REPO
# review review-candidate.json, install the extraction-lock.json.gz written beside it
# as verification/m4/extraction-lock.json.gz, commit
SELECTED_NODE verification/m4/implementation.mjs check NEW_DIRECTORY_OUTSIDE_THE_REPO
```

To reproduce the translator limitations, resolve the selected `charon`,
`aeneas` and extraction-Rust binaries from `policy/tool-selection.json`, and
run the following from either reproducer directory with the record's
temporary environment:

```sh
charon cargo --preset=aeneas --error-on-warnings --inline-anon-consts \
  --dest-file "$OUT/subject.llbc" -- \
  --manifest-path Cargo.toml --lib --all-features \
  --target x86_64-unknown-linux-gnu --locked --offline

aeneas -backend lean -abort-on-error -warnings-as-errors -no-progress-bar \
  -emit-json -split-files -gen-lib-entry -all-computable \
  -dest "$OUT/generated" "$OUT/subject.llbc"
```

Use a private tmpfs work area for `OUT`, `HOME`, `TMPDIR`, `CARGO_HOME`, and
`CARGO_TARGET_DIR`.
