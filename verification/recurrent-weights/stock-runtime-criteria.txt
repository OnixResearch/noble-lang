noble-recurrent-stock-runtime/v1
Status: frozen before any ONNX export or stock-model execution. This rule supplements, never relaxes, criteria.md.
Target: the two already-admitted ngraph-f32/0 one-step graphs and their exact Param snapshots. Export the checked graph and snapshot, not a second hand-written transition. ONNX ModelProto IR version 10, standard-domain opset 18; input and output are ordered FLOAT tensors of 128/64 cells for the accumulator and 128/128 cells for stack swap. No hidden state, external I/O, training, or weights re-fitting.
Runtime: selected flake nixpkgs onnxruntime 1.23.2 CPUExecutionProvider, selected onnx and Python package closures; require reviewed derivation/output identities and store hashes before execution. Execute offline. Other ONNX versions/providers, unselected host interpreters and unselected store outputs cannot contribute to this verdict.
Numeric ABI: each state/input cell is binary32 +0 or 1, little-endian by bit index. Reject wrong shape, nonfinite, -0, non-bit floats, wrong program/configuration, changed graph/model/weights digest, and malformed output. ONNX Where selects on Equal(bit, 1); the host must not compute addition, carry, or stack permutation. Compare decoded output to independently stated wrapping-add or stack-swap semantics and the Noble transparent evaluator; a missing transition is a failure, not zero work.
Coverage: each program exhausts its predeclared tiny domain (accumulator 4x4 state/input; stack swap 4x4 two-word state). Accumulator also checks (0,0), (1,1), (2^64-1,1), (2^63,2^63), (0x5555555555555555,0xaaaaaaaaaaaaaaaa), (0x00000000ffffffff,1). Execute 1,000 teacher-forced and 1,000 free-running stock-model transitions per program, with each mode's count and mismatches separate; never infer long-run results from short checks. The target's own decoded output must be the next free-running state. Report dense, sparse, and stock runtime coverage in separate fields, including explicit 'none' for unexecuted paths.
Refusal controls: corrupted state cell (+0->NaN, +0->-0, +0->0.5), wrong input and output lengths, changed ONNX bytes, wrong program/decoder/codec, insufficient semantic-step budget, cancellation at a transition boundary, illegal snapshot index (negative, >1000, or mid-graph), incomplete checkpoint with recurrent state missing even when extra scratch/KV material is offered. A complete boundary restore must preserve program/configuration/weights identity and remaining budget. The current ONNX host loop has no attention/KV runtime state; reject extraneous hybrid fields rather than presenting synthetic hybrid state as a working restore.
Disposition: DONE only if both exported ONNX artifacts execute under the pinned stock runtime offline and every listed control is exercised and refuses or detects the mismatch. Any failed comparison/control, missing exact pin, unavailable offline closure, or unexecuted full trajectory is BLOCKED or NO-GO, never inferred successful. The existing bounded CPU host-loop GO remains unchanged. Keep test output, source commit, artifact digests, runtime versions/identities, coverage counts, and raw results in a clean-source receipt; retain the verdict in decision.md after the receipt.
