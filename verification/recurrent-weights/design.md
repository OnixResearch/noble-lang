# Design: bounded exact threshold networks

This is a CPU-only, Noble-owned construction experiment, not a neural checkpoint or a general recurrent runtime. Each transition is a finite layered `ngraph-f32/0` graph whose Param snapshot contains exact binary32 coefficients. Bit cells are exactly `+0` or `1`, making finite Boolean gate construction possible without converting arbitrary I64 values to F32. The format's checked `Bit` facts and the existing Param snapshot identity/stale refusal are the relevant substrate; these facts do not by themselves prove this design correct.

Two fixed programs separate arithmetic from routing. The accumulator encodes state and input as 64 little-endian bit cells and implements modulo-$2^{64}$ addition with a bit-level full-adder/carry chain. The routing program swaps two 64-bit stack words. The independent checker consumes only the declared source transition, codec and candidate graph/weight snapshot. It evaluates the candidate over the declared finite domain and compares decoded results with source semantics; the compiler is not an oracle. A faulty candidate must be detectable by this same path.

The baseline is explicitly a host loop around a one-step stateless graph. Host-managed state is serialized between calls; there is no persistent model state. The subsequent unrolled artifact is a statically composed graph with explicit intermediate transition boundaries, capped at four steps. It is not presented as recurrent state held inside weights. Both retain immutable weights and mutable state separately. Only complete state snapshots at transition boundaries may resume, and restoration is bound to the program, codec/configuration, weight identity and remaining budget.

The host supplies input cells, initializes state, schedules graph execution, enforces a maximum of 1,000 semantic steps, checks cancellation at transition boundaries and observes decoded output. It must not calculate carry bits, addition, or the stack permutation. There are no host effects or external inference runtimes in this slice. Stock runtime coverage is therefore none. Any performance claims are limited to the exact CPU evaluator path measured; finite differential tests are not formal proofs, and no evidence transfers automatically to another decoder, runtime, kernel or configuration.

Continuation is governed solely by `criteria.md`; that file was committed before any measurement. No runtime, activation, normalization, rounding, token-selection or decoder-margin behavior outside the exact bit-cell graph is implied. This design refuses unsupported state representations and configurations rather than coercing them.
