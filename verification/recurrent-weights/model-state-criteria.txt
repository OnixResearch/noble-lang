noble-recurrent-model-state/v1
Frozen before any ONNX Scan export or measurement; supplements criteria.md and stock-runtime-criteria.txt without relaxing either.
Target: compile the same two checked ngraph-f32/0 one-step graphs and exact-bit Param snapshots into ONNX IR10/opset18 Scan body graphs. Scan carries an explicit binary32 state tensor between body iterations inside one inference call. Named outer inputs are initial_state_bits and scan_inputs; named outputs are final_state_bits and observations. No per-step host calculation or feedback. Accumulator state/input widths are 64/64 cells. Stack-swap state width is 128 cells and its one-cell-per-step scan token is exactly +0 and otherwise refused. All cells are exact +0/1. Record state bytes, sequence input/output bytes, model bytes and model digest; no persistent session state, KV or attention is claimed.
Runtime: selected ONNX Runtime 1.23.2 CPUExecutionProvider from policy/tool-selection.json, selected ONNX 1.20.1/Python 3.13 closure; disabled optimizations, one thread, offline at inference. The same model bytes must serve different inputs without rebuild or mutation. Refuse another provider, version, graph/configuration or changed model digest.
Comparison: run a one-step Scan against each of the 16 accumulator domain pairs, six arithmetic boundary vectors and 16 stack-swap pairs. Compare every decoded state/observation with independent source semantics and the checked Noble reference/compiled vector. Run 1,000 teacher-forced one-step calls per program with each source-provided state separately; run exactly one 1,000-step Scan call per program whose body carries its own recurrent state, with its complete output trajectory compared step-by-step. Report teacher-forced, single-call free-running, original stateless host-loop, dense and sparse optimized coverage separately. Any mismatch or missing step is a semantic NO-GO, not a timing result.
Controls: refuse NaN, -0, fractional and malformed initial state/input and output cells, wrong state or token shape, wrong program/codec/model identity, changed ONNX bytes, budget shorter than a requested sequence, budget zero at request end, cancellation before inference, illegal negative/>1000/mid-body snapshot indices, wrong remaining budget, absent recurrent state even if KV or scratch material is supplied, and any extraneous hybrid state. Seed a wrong transition in the Scan body and require an independently reported first counterexample. A complete snapshot at a completed boundary (0, 2, 1000) must restore index/configuration/digest/state/budget and resume at index 2 with correct stock outputs. No claim about genuine KV+recurrent hybrid serving.
Cost and disposition: report export/build and runtime load nanoseconds, bytes of model/immutable weights and mutable state, input/output bytes, end-to-end and per-transition nanoseconds, process RSS before/peak, number of host inference calls, model Scan steps, injected tokens and skipped work (must be 0). On the same host/runtime compare the single-call Scan with the stock stateless host-loop receipt; latency ratios are descriptive and do not change the prior bounded CPU GO. DONE only if both programs execute all checks, all controls refuse/detect as declared, one stock inference call carries all 1,000 free-running transitions per program, and every receipt is produced from a clean commit. Otherwise NO-GO for model-held recurrence; no positive result from the earlier host-loop transfers. Retain exact tool/source/graph/model/snapshot digests and raw counts.
