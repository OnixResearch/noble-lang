# noble-rewrite-quality/v1
# Frozen optimization-quality corpus for certified graph rewrites (issue #64).
#
# Each fixture declares its nodes in canonical creation order and the quality target its
# certificate-bearing result must reach. The target is a residual property, not exact text:
# `no-foldable-sites` means `cert::residual_fold_sites` is zero.
#
# Node specifications:
#   const:<decimal>       an I64 constant
#   add:<left>:<right>    an I64 addition of two earlier nodes
#   mul:<left>:<right>    an I64 multiplication of two earlier nodes
#
# This manifest binds the rules it exercises and the source identity it was frozen against;
# a fixture may not be relabelled unsupported to improve coverage.
