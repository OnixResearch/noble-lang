## Why

Noble programs already had exact MC1/MC2 behavioral contracts, but at this change's selection an application author wrote its application proof in a separate Lean module. The original proposal selected a small, explicitly typed proof language **in Noble module source**. In the now-implemented finite opt-in fragment, a Noble author can state a predicative universal theorem, prove equality, and compose a proof of an accepted Noble program's partial-correctness claim. Lean remains the first independent checker target; Bend2 does not become a proof compiler or kernel.
