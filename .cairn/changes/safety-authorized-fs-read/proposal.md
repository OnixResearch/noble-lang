## Why

It requires **one actual guest request**, denial at authorization, and **zero protected file reads**. Static effect refusal (S-CASE-05), the always-denied M5 store fixture and the bounded memory-region adapter do not execute this filesystem case. r[S-EFFECT-03] r[EV-CASE-03]

Only then does the host preopen one vetted regular file under guest key `main.rs`, retain a host-owned invocation Directory and supply independent READ-or-none. No guest WIT Directory owner, native pathname, general filesystem or WASI grant is exposed. r[S-EFFECT-03] r[S-RES-03]

The canonical no-READ run must reach `authorization/denied` after exactly one `fs.read` guest request with zero protected operations. A separate READ-granted invocation of the **same compiled guest** must return only the selected file's bounded bytes and retire its owner; hostile path, grant and handle claims must read nothing. r[RA-STATE-01] r[RA-CLEAN-01] r[EV-CASE-03]
