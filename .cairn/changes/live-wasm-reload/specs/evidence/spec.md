# Live state separation

## ADDED Requirements

### Requirement: EV-LIVE-01
r[EV-LIVE-01]

Before implementation, all live cases MUST remain absent/not-run/open/unassessed with no execution evidence. Later receipts MUST bind exact source/import snapshots, old/new semantic and artifact identities, policy, engine, ABI, bounds and actual publication/refusal; historical receipts remain unchanged. Guest self-edit receipts additionally distinguish checked originating owner/grant/source generation, pinned generation observation, bounded queued byte snapshot versus post-return checked recipe/interface, actual prior invocation requests and stack, derived guest-source origin/digest versus unchanged selected file bytes/hash, and pending/commit/refusal without claiming candidate execution or rollback.
