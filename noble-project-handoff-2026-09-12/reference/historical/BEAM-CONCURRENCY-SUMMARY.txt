## Important choices in this draft

**The kernel stays small; the service platform is standardized.** No actor expression, implicit mailbox, continuation mechanism, or resource-capturing closure is introduced. Pure/configuration hosts may omit concurrency; a host claiming the standard service platform must supply the specified runtime guarantees. This preserves the existing distinction between checked programs and running tasks, and the rule that sequential composition does not imply concurrency. fileciteturn0file4L63-L78 fileciteturn0file4L88-L100

**Tasks have owners, even when their supervising code fails.** Admission atomically registers a child and transfers supported input resources before execution. There is no unrestricted detach operation. Scope cleanup relies on host accounting, not on a crashed supervisor successfully running its finalizers.

**Communication is typed and bounded.** The initial channel contract uses resource-free data payloads, finite message and byte limits, and explicit accounting for blocked senders. Endpoints and reply tokens remain move-only capabilities. Additional send permissions require an explicit host operation rather than generic duplication.

**Restart reconstructs an instance; it does not resurrect one.** Child specifications contain immutable configuration and checked entry programs. Each attempt receives fresh, explicitly authorized resources and a new incarnation identity. The first supervision strategy restarts children independently, with restart budgets, bounded backoff, readiness checks, and shutdown taking precedence over restart.

**Timeout, cancellation, and cleanup are different outcomes.** Request failures preserve the distinction between *not started* and *may have run*. There are no automatic request retries. Native work that cannot be stopped remains owned and charged under an explicit quarantine report rather than being reported as successfully cleaned up.

**Concurrency gets its own verification obligations.** A sequential handle-table proof is not treated as proof of concurrent cancellation, queue safety, or scheduler fairness. Pure transition-function proofs also remain separate from proofs about their effectful runners.
